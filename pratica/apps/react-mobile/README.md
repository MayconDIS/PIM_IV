# Nex_TI Mobile (React Native / Expo)

Aplicativo móvel complementar da plataforma **Nex_TI – EdTech Learning Platform** (PIM IV - UNIP), desenvolvido para permitir que estudantes revisem seus flashcards em qualquer lugar utilizando o algoritmo de repetição espaçada **SM-2** (Motor Anki), acompanhem o ganho de XP e Moedas Dev, e sincronizem o progresso com a API .NET 10.

---

## 🚀 Tecnologias
- **React Native** & **Expo**
- **Algoritmo SM-2 Nativo**: Cálculo matemático do intervalo de repetição e fator de facilidade.
- **Design DNA**: Tokens de cores neon, Dark Mode cyberpunk e tipografia técnica.
- **Shared Packages**: Consumo de `@nexti/shared`.

---

## 📱 Como Rodar

Na raiz do monorepo:
```bash
npm run dev:mobile
```

Ou dentro do diretório `apps/mobile`:
```bash
npx expo start
```
